# Progress block

Прототип кругового блока прогресса для мобильного web-приложения: показывает выполнение процесса в процентах.

## Что умеет блок

- **Значение (Value)** — дуга заполняется по часовой стрелке от положения «12 часов»; при 100% круг замкнут.
- **Анимация (Animate)** — кольцо вращается по часовой с заданным в CSS периодом.
- **Скрытие (Hide)** — блок скрывается с экрана, при этом место под круг сохраняется, чтобы не прыгала вёрстка. При включении Hide анимация выключается.

Логика вынесена в класс **`ProgressBlock`** (`source/scripts/progress-block.js`): через методы можно задавать и читать значение, анимацию и видимость, при необходимости вызвать **`destroy()`** и вернуть разметку контейнера как до инициализации.

## Технологии

HTML, CSS и JavaScript без сторонних библиотек.

## Как открыть

Из-за модулей страницу удобно смотреть через локальный сервер (например `npx serve .` или `python -m http.server`) и открыть `index.html` в браузере.

## Файлы

- `index.html` — страница демо 
- `source/styles/styles.css` — оформление и анимации
- `source/scripts/progress-block.js` — компонент прогресса
- `source/scripts/script.js` — связь полей Value / Animate / Hide с блоком
- `source/fonts/`, `source/images/` — шрифт и иконка при необходимости

Также для текста в проекте добавлен шрифт Report semi-bold.
